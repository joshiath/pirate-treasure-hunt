# Pirate Treasure Hunt

My first Java project published on GitHub.

## Description

Pirate Treasure Hunt is a text-based Java adventure game where the player explores a mysterious island and makes decisions while searching for hidden pirate treasure. Different choices lead to different endings.

## Concepts Used

- Java
- Scanner
- Variables
- String variables
- Numeric variables
- User input
- If / else if / else statements
- Git
- GitHub

## Features

- Multiple paths to explore
- Multiple endings
- Health system
- Hidden treasure
- Ridiculous pirate encounters
